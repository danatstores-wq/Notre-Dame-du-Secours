# Favorites

## Purpose
Let people quickly return to useful parish content without creating an account.

## Supported items
- Prayer-library entries.
- Rosary prayers or mystery guides.
- Priest messages and parish announcements.
- Masses, special liturgies, and parish activities/events.

## User experience
- Add or remove a favorite from the item's detail view and from a visible favorite control.
- Browse saved items from the Favorites bottom-navigation tab.
- Group or filter saved items by content type.
- Show a helpful empty state when no favorites have been saved.
- Keep favorites available offline where the underlying content is cached.

## Storage and privacy
- Favorites are personal preferences and do not modify shared parish content.
- Store favorites locally on the device by default; no account or sign-in is required.
- Do not expose one person's favorites to another user.
- If optional cross-device sync is added later, make it opt-in and secure it per authenticated user.
- Removing an item from favorites must not delete the underlying parish content.

## Languages and accessibility
- Interface labels and empty states support Arabic (RTL), French (LTR), and Italian (LTR).
- Favorite controls must have accessible labels and clear selected/unselected states.

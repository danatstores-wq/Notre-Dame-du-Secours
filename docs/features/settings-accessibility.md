# Settings and Accessibility

## Purpose
Let each person adjust the app on their own device. Settings do not require registration and must not change shared parish content.

## Language
- Arabic, French, and Italian.
- Persist the selected language on the device.
- Arabic uses right-to-left layout; French and Italian use left-to-right layout.
- Apply the selected language consistently to navigation, settings, notifications, forms, validation, and feature screens.

## Notifications
- Link to notification preferences.
- Explain that push notifications require operating-system permission.
- Let users change notification categories and reminder timing.

## Accessibility
- Provide readable text-size choices.
- Respect operating-system accessibility settings where possible.
- Maintain sufficient contrast, clear focus states, screen-reader labels, and appropriately sized touch targets.
- Do not rely on color alone to communicate status.

## Privacy and app information
- Provide the parish-approved privacy notice.
- Explain that registration is needed only to submit a prayer request.
- Show app version and a way to contact the parish using approved public details.

## Storage and account
- Save language, accessibility, and notification preferences locally.
- Do not require an account for settings.
- If a user signs in to submit prayer requests, provide a clear sign-out option without affecting public app access.
- Do not store passwords locally or in plain text.

## Security
- Personal settings must be scoped to the local device or the authenticated user's own profile.
- Users must not be able to change parish-wide settings or administrator permissions.

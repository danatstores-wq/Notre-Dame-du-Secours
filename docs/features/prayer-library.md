# Prayer Library — Arabic, French & Italian

Trilingual prayer library: Arabic (RTL), French (LTR), and Italian (LTR). Starter content: Our Father, Hail Mary, Glory Be, a thanksgiving prayer, and a prayer for peace.

Features planned: category browsing, search, offline reading, adjustable text size, copy/share, and personal favorites. Audio will be added only when authentic approved recordings are supplied. Shared content is priest-controlled; ordinary users are read-only. Starter translations should be reviewed by parish clergy before release; further categories (morning/evening, sick, Communion, special occasions) will be expanded.
